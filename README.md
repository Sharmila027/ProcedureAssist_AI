# Procedure Assist AI

AI-Powered Citizen Guidance Platform for Government Procedures.

## Project Structure

- backend - FastAPI backend and AI services
- frontend - User interface
- knowledge_base - Government procedure knowledge
- tests - Testing
- docs - Project documentation

## Core Features

- Government procedure guidance
- User-selected language
- Multi-language interaction
- Document upload
- OCR
- AI-powered guidance
- Retrieval Augmented Generation
- Government knowledge base
- Source references
- Personalized responses
- User feedback
